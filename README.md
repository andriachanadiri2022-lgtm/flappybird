# ფრთების რხევა

ქართულენოვანი, მობილურზე მორგებული Flappy Bird-ის შთაგონებით შექმნილი თამაში. პროექტი არის დამოუკიდებელი HTML ფაილი და არ საჭიროებს დამატებით ბიბლიოთეკებს ან build-ს.

## თამაში

გახსენით `index.html` ბრაუზერში. დააჭირეთ `Space`-ს ან `↑`-ს, ან შეეხეთ სათამაშო მოედანს, რომ ჩიტმა ფრთები ააფრიალოს. რეკორდი ინახება ბრაუზერის `localStorage`-ში.

## GitHub Pages-ზე გამოქვეყნება

1. GitHub-ზე შექმენით ახალი, საჯარო რეპოზიტორია, მაგალითად `flappy-bird`.
2. ატვირთეთ ამ საქაღალდის ფაილები ისე, რომ `index.html` რეპოზიტორიის ზედა დონეზე იყოს.
3. რეპოზიტორიაში გახსენით **Settings → Pages**.
4. **Build and deployment** განყოფილებაში აირჩიეთ **Deploy from a branch**, შემდეგ `main` და `/(root)`, და დააჭირეთ **Save**.
5. რამდენიმე წუთში თამაში ხელმისაწვდომი იქნება მისამართზე `https://<მომხმარებელი>.github.io/<რეპოზიტორია>/`.
